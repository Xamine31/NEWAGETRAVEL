# V18.12 — Préparation référencement Google

Ajouts techniques SEO sans modification du design :
- robots.txt
- sitemap.xml
- titres et descriptions uniques sur les pages principales
- URL canoniques sur www.newagetravel.fr
- Open Graph / Twitter cards
- données structurées Schema.org TravelAgency / LocalBusiness
- pages d’administration en noindex
- anciennes pages HTML marquées noindex avec canonique vers les URL propres

Après mise en ligne : ajouter https://www.newagetravel.fr dans Google Search Console, valider le domaine puis envoyer https://www.newagetravel.fr/sitemap.xml.
