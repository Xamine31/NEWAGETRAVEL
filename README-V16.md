# New Age Travel — V16

Cette version reprend toute la V15 et applique la direction graphique validée : identité bleue conservée, logo existant inchangé, fonds en dégradés bleu/turquoise avec accents doré, corail et lavande, boutons plus vivants et administration harmonisée.

## Installation
Remplace les fichiers du site par ceux de cette archive. Conserve ton `supabase-config.js` réel si celui du serveur contient déjà tes identifiants publics Supabase.

## Base Supabase
Aucune nouvelle migration n'est nécessaire pour V16. Si V14/V15 n'ont jamais été installées, exécute une seule fois `supabase/v14-combined-migration.sql`.
