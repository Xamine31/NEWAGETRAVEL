# New Age Travel — V18.21

## Nouveautés
- Les réglages Animation / Police / Couleur sont maintenant placés directement sous chacun des trois champs de l’accueil : Petit titre, Titre principal, Texte principal.
- Chaque période d’un voyage peut avoir son propre prix affiché et son propre prix numérique.
- Sur la fiche voyage, le prix se met à jour automatiquement lorsque le client change de période.
- Le prix choisi apparaît aussi dans le récapitulatif avant envoi de la demande.
- Si une période n’a pas de prix spécifique, le prix général du voyage est utilisé.

## Supabase
Exécuter une fois `supabase/v18-21-voyage-date-prices.sql` dans le SQL Editor avant d’enregistrer des prix par période.

## Déploiement
Conserver votre `supabase-config.js` réel lors du remplacement des fichiers du site.
