# New Age Travel France — version dynamique

Site vitrine moderne, responsive et compatible GitHub Pages.

## Installation GitHub Pages

1. Créez un dépôt GitHub.
2. Copiez **tout le contenu de ce dossier** à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez `Deploy from a branch`, puis `main` et `/ (root)`.
4. Attendez la publication du site.

## Modifier le contenu

Les destinations, offres et publications sont dans `data.json`. Les images sont dans `assets/`.

La version est dite « dynamique » car l'interface génère les cartes et les pages à partir de `data.json`, sans backend. Elle fonctionne donc sur GitHub Pages.

## Important

Les prix, dates et prestations repris des captures fournies sont des données de démonstration et doivent être vérifiés auprès de l'agence avant publication commerciale.

Le formulaire de contact prépare un email via `mailto:`. Pour un vrai formulaire en ligne sans messagerie locale, il faudra ensuite connecter un service de formulaire.
